# SBCB Tech Catch-ups

We are the Structural Bioinformatics and Computational Biochemistry Unit (SBCB) at the Department of Biochemistry, University of Oxford. 

Welcome to the shared knowledge base for our weekly informal catch-ups. Each meeting page records the software/computing resource we looked at, a short summary of the discussion, useful technical points, and links worth revisiting.

Use the **search** box to find terms across all notes, browse the **meeting archive** chronologically, or use the **tag index** to discover meetings by topic.

## Writing a meeting note

Start from `docs/meetings/TEMPLATE.md` in the source repository rather than from a blank file. A useful note should normally contain:

1. **Tags** — a small set of reusable topics from the vocabulary above.
2. **Resource watched** — title, link, speaker/author where useful.
3. **Summary and takeaways** — a few sentences explaining what the session was about, concise points that will still be useful later.
4. **Resources** — documentation, repositories, papers, tutorials, wikis, or tools mentioned.

!!! note
    The template file is deliberately excluded from the rendered site, so it can contain placeholders without appearing in search results.
